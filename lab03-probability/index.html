陽性，然後呢

一個敏感度 90% 的快篩，驗出陽性——這尾魚真的有病嗎？ 大部分人會說「九成吧」。正確答案是 48.6%，連一半都不到。 這一頁用滑桿讓你看著這個數字怎麼隨盛行率崩塌，最後再用一千次抽樣， 親眼看歪掉的母體怎麼變成鐘形。

雙向表：本週所有計算的基礎

機率題九成的難處不在公式，而在沒把表畫出來。 只要四格填滿，邊際、聯合、條件機率全都是「用數的」。改下面的數字試試看。

目標種為主混獲為主合計
拖網 —
刺網 —
合計 — — —

互斥 Mutually Exclusive
  • 不可能同時發生，P(A ∩ B) = 0
  • 加法規則簡化為 P(A) + P(B)
  • 例：同一網次是「拖網」或「刺網」
獨立 Independent
  • 一個發生不影響另一個的機率
  • 判準：P(A|B) = P(A)
  • 例：兩次不同網次的漁獲結果
互斥 ≠ 獨立

這是本單元最常搞混的一組。
互斥講的是「不能同時發生」；獨立講的是「互不影響」。
而且——兩個機率都不為零的互斥事件，一定不獨立。 因為 A 一發生，B 就絕不可能發生，這是最強的相依。

02

篩檢的陷阱

敏感度是「有病驗得出來」的比例；陽性預測值是「驗出陽性真的有病」的比例。 兩者條件方向相反，卻經常被當成同一件事——這是條件機率最經典的誤用。

實驗 02 拉動盛行率，看 PPV 崩塌 每個點代表 1 尾魚，共 1000 尾
真陽性 TP（有病，驗出陽性） 偽陽性 FP（沒病，卻驗出陽性） 偽陰性 FN（有病，卻驗成陰性） 真陰性 TN（沒病，驗成陰性）

把盛行率拉到 1% 看看

即使敏感度與特異度都維持在 90%／95%， 陽性預測值會掉到 16% 左右——驗出陽性的個體裡，有八成其實是健康的。
原因很單純：健康的實在太多了。就算誤判率只有 5%， 乘上龐大的健康族群，產生的偽陽性也會蓋過真陽性。

實務對策

對低盛行率的疾病做全面普篩，會製造大量偽陽性，造成不必要的撲殺與損失。
正確做法是先用流行病學資訊縮小範圍（只篩高風險池區）， 把受檢族群的盛行率提高，PPV 才會跟著上升；陽性個體也必須用更精確的第二階段檢驗複驗。

03

二項分配探索器

成功或失敗、存活或死亡、雌性或雄性——生物研究裡最常出現的就是這種「只有兩種結果」的情境。 拉動 n 與 p，看整個分配的形狀怎麼變。

實驗 03 n 與 p 怎麼決定形狀 把 p 拉到 0.5 看看會發生什麼

二項實驗的四項條件

#條件英文標識放流的對應
1固定的試驗次數 nFixed number of trials放流 20 尾，n = 20
2每次只有兩種結果Two outcomes回收 / 未回收
3每次成功機率 p 相同Constant probability每尾回收率都是 0.15
4各次試驗互相獨立Independent trials一尾被回收不影響其他尾
第 3、4 條最容易被違反

例如「不放回抽樣」就違反第 3 條——抽走一個之後機率就變了，這時要改用超幾何分配。

第 8 週的經驗法則（68-95-99.7）其實就是常態分配的三個特例。 這台機器讓你算任何區間——而且會把面積塗給你看。

實驗 04 面積就是機率 正向與反向都能練

正向題反向題
題目給你一個數值 x一個機率或百分比
要你求機率數值 x（臨界值）
步驟x → z → 查表 → 機率機率 → 反查表 → z → x
公式z = (x − μ) / σx = μ + z·σ
典型問法超過 280 g 的比例是多少最重的 10% 門檻在哪
三個必背的臨界值

z = 1.28（尾端 10%）　z = 1.645（尾端 5%）　z = 1.96（尾端 2.5%）
後兩個下學期會天天用到——1.645 用於單尾檢定，1.96 用於 95% 信賴區間。

中央極限定理模擬器　★

這是全學期最值得動手玩的一個模擬。 挑一個歪七扭八的母體，設定樣本數，按下按鈕抽一千次—— 然後看著樣本平均數的直方圖，自己變成鐘形。

實驗 05 母體再怎麼歪，x̄ 還是會變鐘形 先選母體，再選 n，然後按「抽 1000 次」
母體分配

個別個體長什麼樣子——這是「歪的」那一個

x̄ 的抽樣分配

每次抽 n 個算平均，把那些平均數畫成直方圖

尚未開始。先按「抽 1000 次」。

試試這個順序

① 選右偏母體，n 設為 1，抽 1000 次——右邊的圖跟左邊一樣歪。
② 把 n 改成 5，再抽——已經開始對稱了。
③ 改成 30，再抽——幾乎是完美的鐘形，而且窄了很多。
④ 換雙峰母體重做一次。中間明明是凹的，x̄ 卻還是變成單峰鐘形。

中央極限定理

#定理內容意思
1x̄ 的平均數 = μx̄ 不會系統性偏高或偏低（不偏）
2x̄ 的標準差 = σ / √n樣本越大，x̄ 越集中——這叫標準誤
3n 夠大時 x̄ 趨近常態不管母體長什麼樣　★ 最神奇的一條
本週最常見的失分點

問「一尾魚」用 σ；問「n 尾的平均」用 σ/√n。
看到「平均」兩個字就要換分母。

本學期的終點，下學期的起點

既然 x̄ ~ N(μ, σ²/n)，那麼有 95% 的機會 x̄ 落在 μ ± 1.96 個標準誤之內。
把它反過來寫：有 95% 的機會，μ 落在 x̄ ± 1.96 個標準誤之內。
這就是「95% 信賴區間」——下學期第 1 週的第一個公式。

速記卡

項目公式備註
餘事件P(E') = 1 − P(E)「至少一次」改算「一次都沒有」
加法規則P(A ∪ B) = P(A) + P(B) − P(A ∩ B)互斥時第三項為 0
條件機率P(A|B) = P(A ∩ B) / P(B)分母＝縮小後的樣本空間
乘法規則P(A ∩ B) = P(A) × P(B|A)
獨立的判準P(A|B) = P(A)不相等就是不獨立
排列nPr = n! / (n−r)!順序有差
組合nCr = n! / [r!(n−r)!]順序無差
期望值μ = Σ[X · P(X)]長期平均，非單次預測
離散變異數σ² = Σ[X² · P(X)] − μ²
二項機率P(X=x) = nCx · p^x · q^(n−x)四項條件要先檢查
二項的 μ、σμ = np　σ = √(npq)
標準化z = (x − μ) / σ問「一尾」用這個
反標準化x = μ + z·σ反向題用這個
標準誤SE = σ / √n問「n 尾的平均」用這個
x̄ 的標準化z = (x̄ − μ) / (σ/√n)★ 最常錯的地方
五個最容易錯的地方

① 互斥 ≠ 獨立——互斥是不能同時發生，獨立是互不影響
② 敏感度 ≠ 陽性預測值——條件方向相反
③ 二項的四項條件要逐一檢查，特別是「p 是否相同」
④ 正向題與反向題方向要分清楚
⑤ 問「平均」卻用 σ 當分母——必須用 σ/√n
